# One Click Folder

Googleドライブに共有フォルダを1クリックで作る、個人用のWindowsツールの公開情報です。

[アプリの説明とプライバシーポリシー](https://mrpepper5641.github.io/oneclick-folder/)

## このリポジトリについて

- ここにあるのは説明ページと、このREADMEだけです。
- 実行ファイルはここでは配布していません。
- 個人利用のためのツールで、一般向けの配布やサポートは行っていません。

## 注意

- 「One Click Folder」を名乗るファイルをネットから入手して実行しないでください。
- 心当たりのない「One Click Folder」の許可画面が表示されたら、許可しないでください。

## アプリが行うこと

- 許可したGoogleアカウントのドライブにフォルダを作り、リンク共有を設定します。
- 使用する権限はGoogle Driveの `drive.file` のみで、このアプリが作ったフォルダだけを扱います。
- データの送信先はGoogleのみで、開発者や第三者には送信しません。

## 許可を取り消す

[Googleアカウントの権限ページ](https://myaccount.google.com/permissions)で、One Click Folderのアクセスを削除してください。

## 利用の禁止事項

このツールや作成した共有リンクを、スパム、マルウェアの配布、権利侵害、他人のアカウントの無断利用に使うことを禁止します。
